Internal Consumption

Internal Consumption is a simple module that allow you to record products that were originally meant for sale by the company, but later being consumed internally. This module will decrease inventory quantity and later post a journal entry based on the chosen account during creation.

Features

Can Be Set For Certain User

Only certain user which given privilege can access this module.

Simple To Use

Simply create the record, insert product and accounts, and we are good to go.

Decrease Your Stock Easily

When internal consumption are validated, it will reduce the inventory quantity.

Recorded Into Accounting Module

Journal entry will be created based on account you have choosen.

Stock Moves Will Also Created

Decreased product is also noticeable from In/Out (Stock Moves).
